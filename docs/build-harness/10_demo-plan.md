# Demo plan

## Thesis

In 90 seconds, prove that fragmented SME activity becomes an evidence-backed decision, the safest financing option settles on Base, and repayment changes the Business Graph.

## Script

1. **Business Data (10s):** show Ada's Pharmacy fixture and the supplier-before-receivable timing.
2. **Understand (10s):** ask, “Can I still place this inventory order?” Show inputs and evidence references.
3. **Simulate (15s):** compare baseline, 20% sales decline, and seven-day late receivable.
4. **Decide (10s):** show reduce/defer alternatives before the smaller cash-plus-facility recommendation.
5. **Finance (10s):** show exact terms, policy version, risk flags, and human approval.
6. **Base Settlement (15s):** confirm deployment/register/draw wallet transactions and explorer receipts.
7. **Repay (10s):** confirm exact USDC repayment receipt.
8. **Updated History (10s):** show graph version/history change linked to the receipt.

## Required environment

Base Sepolia, authorized test wallet, test ETH, sufficient Base Sepolia test USDC, local API/store, frontend, and a clean browser wallet.

## Must-show failure

Attempt a duplicate offer or wrong-chain action and show the fail-closed error.

## Backup

Use a recording of a previously completed REAL — TESTNET run with visible explorer evidence. Never substitute simulated hashes.
