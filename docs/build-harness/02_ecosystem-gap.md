# Ecosystem gap

## Thesis

Base provides programmable settlement and USDC infrastructure, but an African SME still needs privacy-preserving middleware that converts offchain operating evidence into explainable decisions, controlled financing, verifiable settlement, and updated financial history.

## Why Base

- Default network: Base Sepolia, chain ID 84532.
- Load-bearing target: financing agreements, drawdowns, repayments, status, and evidence commitments.
- Private bank, POS, invoice, and supplier records remain offchain.
- Portability: the offchain engine is portable; Base is the intended default settlement and public evidence layer.

## Ecosystem value

Kora can create a new category of Base-first financial operations in which transactions are justified by business context and produce reusable, verifiable performance history.

## Alternatives

| Solution | What it does | Kora difference |
|---|---|---|
| Accounting/ERP | Records business activity | Kora links activity to simulation, policy, capital, and settlement |
| Lending workflow | Underwrites an application | Kora detects contextual need after testing alternatives |
| Wallet app | Sends onchain transactions | Kora keeps sensitive evidence offchain and binds approved terms to commitments |

## Missing primitive test

Without Kora, developers still lack a tested reference loop joining private business evidence to explainable working-capital decisions and Base settlement receipts.
